# Email Spam Detection Using Machine Learning

## 📌 Project Overview

Email Spam Detection is a machine learning project that classifies emails as **Spam** or **Not Spam (Ham)** using text processing and classification algorithms. The system analyzes email content to identify unwanted messages and helps improve email security.

## 🎯 Objectives

- Detect spam emails automatically.
- Classify emails as spam or legitimate.
- Apply machine learning algorithms to text data.
- Evaluate model performance using suitable metrics.
- Reduce unwanted and potentially harmful emails.

## 🛠️ Technologies Used

- Python
- Google Colab
- Pandas
- NumPy
- Scikit-learn
- Natural Language Processing (NLP)
- TF-IDF Vectorization
- Matplotlib and Seaborn

## ⚙️ Project Workflow

1. Load the email dataset.
2. Clean and preprocess email text.
3. Convert text into numerical features using TF-IDF or other suitable methods.
4. Split the dataset into training and testing sets.
5. Train machine learning classification models.
6. Evaluate performance using accuracy, precision, recall, and F1-score.
7. Predict whether new emails are spam or legitimate.

## 🤖 Algorithms

Depending on the notebook implementation, the project can use:

- Naive Bayes

- Support Vector Machine (SVM)
- Decision Tree
- Random Forest
